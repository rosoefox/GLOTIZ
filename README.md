# JB-XPORT

전북 로컬 특산물·소상공인 수출·마케팅 AI 에이전트 (UI 프로토타입)

> 현재는 백엔드/AI 연동 없이 UI만 구현된 상태이며, 모든 데이터는 `src/data/mockData.js`의 더미 데이터를 사용합니다.

## 실행 방법

git 프로젝트 메인 화면에서 초록색 CODE 버튼 클릭
다운로드 .zip으로 하기

압축 풀기 ->
압축 푼 폴더를 VS CODE에서 열기

VS CODE 터미널에서 
```
cd web
npm install
npm run dev
```

터미널에 나오는 주소(기본값 http://localhost:5173)를 브라우저에서 열면 됩니다.

종료하고 싶으면 터미널에서 Ctrl + C
